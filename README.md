# 🛡️ Math Defender

수학 문제를 풀어 자원을 얻고, 그 자원으로 다음 행동을 선택하는 **수학 전략·디펜스 게임**입니다.

핵심 루프는 **문제 풀이 → 정찰 → 방어**입니다.

## 🚧 Status

현재 개발 중인 프로젝트입니다. 이 공개 저장소는 Math Defender의 공개 배포·프로젝트 소개·개발 일지를 위한 공간이며, 게임의 비공개 개발 소스 전체를 포함하지 않습니다.
