# 🛡️ Math Defender

수학 문제를 풀어 자원을 얻고, 그 자원으로 다음 행동을 선택하는 **수학 전략·디펜스 게임**입니다.

핵심 루프는 **문제 풀이 → 정찰 → 방어**입니다. 문제 풀이를 단순한 퀴즈가 아니라 다음 전략을 실행하기 위한 자원 획득 과정으로 연결하는 것을 목표로 합니다.

## 🚧 Status

현재 개발 중인 프로젝트입니다.

이 공개 저장소는 프로젝트 소개를 위한 공간이며, 게임의 개발 소스 전체가 공개되어 있지는 않습니다.

## 🎯 Design Goals

- 문제 풀이와 전략적 선택을 하나의 게임 루프로 연결하기
- 정답 보상을 다음 의사결정에 의미 있는 자원으로 사용하기
- 플레이어가 자신의 선택과 결과를 쉽게 이해하게 만들기
- 작은 플레이어블 빌드로 반복 검증하며 개선하기
